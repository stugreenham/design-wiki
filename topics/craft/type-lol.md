# Type.lol

## What it is

An index of independent type foundries from around the world: 900+ foundries, 18,000+ typefaces and 2,700+ type designers to browse.

## When I'd use it

Looking for a typeface beyond the usual Google Fonts and big foundries, or discovering independent type designers.
