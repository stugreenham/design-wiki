# mkdir

## What it is

A directory of web design inspiration directories: 34 galleries, award sites and section libraries, all free with no paywall or account. Visitors vote for the ones they use, and the ranking updates from those votes. It includes Awwwards, Recent, CollectUI, One Page Love, Land-book, Siteinspire, Footer.design, Navbar Gallery, Dark Mode Design and more.
