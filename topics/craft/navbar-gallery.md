# Navbar Gallery

## What it is

A gallery of website navigation designs, sorted by type: static and sticky bars, dropdowns, mega menus, sidebars, search bars, announcement bars, full screen menus and breadcrumbs. Each type has a short explanation of when it's used.

## When I'd use it

Designing or reviewing site navigation and wanting real examples of a specific pattern.
