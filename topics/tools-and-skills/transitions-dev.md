# Transitions.dev

## What it is

A library of 43+ ready made UI transitions (card resize, number pop-in, menu dropdown, modal open and close and more) that you can remix and drop into HTML/CSS or React. It also has an AI component builder, a Motion Agent that finds and fixes janky motion, and a Motion Skill that teaches coding agents these transitions. Free to browse, with a Pro tier.

## When I'd use it

Adding polished motion to a prototype or product without building every transition from scratch.
