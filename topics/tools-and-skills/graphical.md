# Graphical

## What it is

A tool for creating a visual theme for an interface, then building with it through the AI coding agent you already use (ChatGPT, Claude, Cursor and others). You set the style, character (airy, quiet, bold, compact), motion, colours, typography and icons, and preview them on real components. The theme downloads directly or installs into a project via shadcn. Agents read it from a `GUI.md` file, a similar idea to DESIGN.md.

## When I'd use it

Setting up the look and feel for a new product or prototype before building it with an AI agent, so everything it generates stays on brand.
