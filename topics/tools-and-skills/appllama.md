# Appllama

## What it is

A reference library of 70,000+ screens from 1,500+ top grossing iOS apps. You can browse screens, flows and UI elements like onboarding and paywalls, with revenue and download context for each app. Free to start, with a paid Pro tier and an MCP connection for AI tools.

## When I'd use it

Researching how successful apps handle a specific flow, like onboarding, sign up or a paywall, before designing my own.
