# ScreensDesign

## What it is

A library of full screen recordings from about 2,800 top-charting iOS apps, from the first screen through to after purchase. Every screen is tagged, so you can search for things like "meditation paywalls with a free trial, sorted by revenue". It has an MCP so AI agents can search it, plus an AI screen generator based on the examples. Has a paid Pro tier.

## When I'd use it

Researching how successful apps handle onboarding, paywalls and other key flows. Very similar to Appllama, so worth comparing the two and keeping the one you prefer.
