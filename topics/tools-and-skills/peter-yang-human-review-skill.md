# Peter Yang's /human-review skill

## Summary

After `/no-ai-slop` got 4K GitHub stars, Peter Yang released `/human-review`, a free AI skill. It opens HTML and Markdown files in a visual editor so you can edit text yourself, resize images and leave Google Doc style comments for the AI, instead of describing every change in chat.

## Key takeaways

- **Giving feedback in chat is clunky.** "Update the third paragraph" is slower than just clicking and editing
- **Edit in place, then comment for the AI.** Mixes direct editing with AI help, like a shared doc
- **Good for** PRDs, landing pages and product copy
- **Runs locally.** Though a commenter rightly points out the connected AI agent may still send content to its provider
- Free on GitHub: [petergyang/human-review](https://github.com/petergyang/human-review)
