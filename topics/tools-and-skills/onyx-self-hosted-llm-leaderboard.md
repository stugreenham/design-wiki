# Self-hosted LLM leaderboard (Onyx)

## What it is

A regularly updated ranking of open-weight AI models you can host yourself (Llama, DeepSeek, Qwen, Mistral and more). It compares quality, speed, hardware needs, cost and licensing, and ranks models by task. Aimed at companies, but a useful overview for anyone.

## When I'd use it

Comparing open models when picking one to run privately, or just keeping up with which open models are best right now.
