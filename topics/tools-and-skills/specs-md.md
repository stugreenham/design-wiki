# specs.md: spec-driven AI development

## What it is

An open framework for building with AI coding agents by writing specs first. It offers four "flows" depending on the job: Ideation (brainstorm ideas into concept briefs), Simple (quick requirements, design and task docs), FIRE, and AI-DLC (a fuller development lifecycle). It compares itself to GitHub Spec Kit, Kiro and OpenSpec.

## When I'd use it

When moving from a design idea to something an AI agent builds, and I want the requirements written down properly rather than prompting on the fly.
