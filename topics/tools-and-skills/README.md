# Tools and Skills

Things you can install or use in your workflow: design tools, AI agent skills, spec frameworks and more. For the thinking behind AI and design, see [AI and Design](../ai-and-design/README.md).

## Design tools

- [Appllama](appllama.md): screens and flows from top-grossing iOS apps, with an MCP for AI tools
- [ScreensDesign](screensdesign.md): searchable recordings of top iOS app flows, with an MCP. Similar to Appllama
- [ButterKit](butterkit.md): Mac app for App Store screenshots, translated into 50 languages
- [Graphical](graphical.md): build a visual theme, then let your AI coding agent build with it
- [Transitions.dev](transitions-dev.md): ready-made UI transitions plus motion tools for AI agents

## AI generation

- [Midjourney: Style Reference](midjourney-style-reference.md): how to keep a consistent look across generated images
- [Playground](playground-design.md): AI tool for quick graphics like logos, posters and social posts
- [MotionSites](motionsites.md): ready-made AI prompts for landing pages and sections

## AI agent skills

- [Karl Koch's design engineering skills](karl-koch-design-engineering-skills.md): about 20 AI skills for design engineering reviews
- [Jakub Krehel's /state-machine skill](jakub-krehel-state-machine-skill.md): see every state of a component on one throwaway page
- [Peter Yang's /human-review skill](peter-yang-human-review-skill.md): edit and comment on AI output visually, instead of in chat

## Spec frameworks

- [Self-hosted LLM leaderboard (Onyx)](onyx-self-hosted-llm-leaderboard.md): rankings of open models by quality, speed and cost
