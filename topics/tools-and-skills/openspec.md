# OpenSpec

## What it is

A free, open source framework for writing and managing specs that AI coding agents follow. You capture what you want to build in a spec, then it helps refine the requirements, build from them, and check the result matches. It's very widely used (70,000+ GitHub stars) and works with Claude Code, Cursor, Codex, Copilot and many more.

The workflow has five commands:
- **explore:** map the problem and the codebase
- **propose:** draft the proposal, specs, design notes and tasks
- **apply:** build from the spec
- **verify:** check the build matches the spec
- **archive:** file away finished changes

## When I'd use it

When I want a lightweight way to turn design intent into a written spec an AI agent will build from and check against.
