# MotionSites

## What it is

A library of ready-to-use AI prompts for building landing pages and sections (heroes, pricing, social), with new prompts added daily. You copy a prompt into an AI builder and get a styled page. It also offers backgrounds, 3D assets, a restyle tool and an MCP. Has paid plans.

## When I'd use it

Getting a strong starting point for a landing page built with AI, rather than prompting from scratch.
