# Can I Run AI?

## What it is

Detects your computer's GPU or Mac chip and shows which open AI models (chat, coding, image and video) will run on it locally, with memory needs, speed estimates and a grade for each.

## When I'd use it

Before downloading a model to run on my own machine, to check it will actually work.
