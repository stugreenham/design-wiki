# Jakub Krehel's /state-machine skill

## Summary

Jakub, a founding design engineer at Interfere and the person behind Interfaces magazine, added a `/state-machine` skill to an open source collection. It renders a component in every one of its states on a throwaway page, with mock data and a switcher, which makes complex components much easier to work on.

## Key takeaways

- **See every state at once:** loading, empty, error and so on, without clicking through the real app
- **Throwaway page with mock data,** so the real codebase stays clean
- **Part of a bigger set** of skills at [jakubkrehel/skills](https://github.com/jakubkrehel/skills): `better-ui`, `better-typography`, `better-colors`, `better-accessibility`, `better-layout`, `better-writing`, plus `variant` (build and compare options) and `break` (stress test a component)
- Installs as a Claude Code plugin or with `npx skills add jakubkrehel/skills`
