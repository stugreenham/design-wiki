# Hugging Face

## What it is

The main hub for open source AI. It hosts hundreds of thousands of models (text, image, audio, video), datasets, and "Spaces" where you can try models in the browser without installing anything.

## When I'd use it

Finding and trying open AI models, for example an image or voice model to prototype with.
