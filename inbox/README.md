# Inbox

Drop raw finds here when there's no time to write them up. A link and a one line note is enough.

Example file `inbox/2026-10-19-notes.md`:

```
- https://www.linkedin.com/posts/... : great point about AI replacing handoff docs
- https://x.com/... : new Figma feature, worth a look
```

Items get turned into proper entries in `topics/` and then removed from here.
